AVORY 업무 관리 · 설치 방법 (무료, Claude 없이 동작)

[1] 인터넷 주소 만들기 (PC에서 한 번만, 약 10분)
 1. github.com 에서 무료 가입
 2. 오른쪽 위 + → New repository → 이름: avory → Public 선택 → Create repository
 3. "uploading an existing file" 링크 → 이 폴더의 파일 전부(index.html, sw.js, manifest.webmanifest, icon 4개)를 끌어다 놓기 → Commit changes
 4. 저장소 Settings → Pages → Branch: main, 폴더 / (root) → Save
 5. 1~2분 뒤 주소가 생겨요: https://(내아이디).github.io/avory/

[2] 아이폰
 1. 사파리로 위 주소 열기 → 공유 버튼 → 홈 화면에 추가
 2. 반드시 홈 화면 아이콘으로 열고 → 설정(톱니) → 앱 설정 → 백업 불러오기 → 백업 파일 선택
    (홈 화면 앱과 사파리 탭은 저장 공간이 달라요. 홈 화면 앱 안에서 불러오세요)

[3] PC
 - 크롬/엣지로 같은 주소 열기 → 주소창 오른쪽 '설치' 아이콘 → 백업 불러오기
 - 인터넷 주소 없이도 이 폴더의 index.html을 크롬으로 열면 PC에서는 바로 써져요

[4] 백업 · 새 폰
 - 설정 → 앱 설정 → 백업 파일 받기 (일주일에 한 번 권장)
 - 새 폰: 앱 설치 → 백업 불러오기 → '이 백업으로 바꾸기'
 - PC와 폰 같이 쓰기: 한쪽 백업을 다른 쪽에서 '합치기'로 불러오기

[5] 앱 업데이트
 - 새 index.html을 받으면 GitHub 저장소에 같은 이름으로 다시 올리기 → 폰은 다음에 열 때 자동으로 새 버전

주의: 백업 파일(AVORY_백업_….json)에는 계좌·거래 내역이 들어 있어요. GitHub에는 절대 올리지 마세요.
